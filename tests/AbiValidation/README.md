# VLC ABI validation

`vlclr_abi.g.cpp` is a compile-only probe generated by `tools/VLCLR.CImport`
(`emit`) from the pinned VLC headers. It checks the sizes, field offsets and
constant values of the generated interop structs in `src/VLCLR/Native/Interop`
against what the C/C++ compiler computes from the VLC headers. Any difference
fails at compile time through a C++ `static_assert`. Do not edit it by hand;
regenerate it with the emit command (see `tools/VLCLR.CImport`).

Fetch the pinned headers first, then compile the probe against them:

```powershell
tools\VLCLR.CImport\fetch-headers.ps1
tests\AbiValidation\verify-vlc-abi.cmd artifacts\vlc-headers\include   # MSVC
```

```bash
tools/VLCLR.CImport/fetch-headers.sh
tests/AbiValidation/verify-vlc-abi.sh artifacts/vlc-headers/include    # GCC or Clang
```

CI (cross-platform.yml) runs the probe on Linux, both macOS flavours and
Windows/MSVC against the pinned headers, and also against the headers of the
latest VLC nightly. A failure against the nightly is a real drift signal: VLC
changed a layout since the pinned commit.
